## Overview

A static, multi-page personal portfolio hosted on GitHub Pages. Built without any frameworks or build tools — just structured HTML and CSS. The focus is on semantic markup, consistent navigation, and a minimal layout that keeps the content front and centre.

---

## Site Structure

```
PortFolio/
│
├── index.html        ← Landing page & introduction
├── exp.html          ← Education & academic background
├── port.html         ← Project showcase
├── cont.html         ← Contact form & details

└── images.jpg        ← Profile photo
```
